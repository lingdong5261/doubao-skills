# 指标口径、维度与预警规则

日报里的每个数字都必须能追到这张表的定义。**口径一旦改动，要同步改 `scripts/daily_report.py`**，否则脚本和文档会打架。

## 1. 核心指标

| 指标 | 定义 | 数据来源 |
|---|---|---|
| 台班数 | 当日 `台班数` 字段求和，单位「个台班」；半天按 0.5 计 | 台班记录 |
| 收入（台班产值） | Σ(`台班数`×`台班单价` + `加班小时`×`加班单价`)，即「收入金额」字段求和 | 台班记录 |
| 回款 | 当日 `回款金额` 求和 | 回款记录 |
| 出勤设备数 | 当日有台班记录的设备去重数 | 台班记录 × 设备台账 |
| 在册设备数 | 设备状态 ≠ 「停用」的设备数 | 设备台账 |
| 出勤率 | 出勤设备数 / 在册设备数 × 100% | 计算 |
| 闲置设备数 | 状态=待租，且当日零台班的设备数 | 设备台账 × 台班记录 |
| 直接成本 | 当日 `金额` 求和，费用类型 ∈ {柴油, 维修, 配件, 司机工资, 过路费, 吊索具, 其他} | 成本支出 |
| 毛利 | 收入 − 直接成本 | 计算 |
| 毛利率 | 毛利 / 收入 × 100%（收入为 0 时留空，不写 0%） | 计算 |
| 应收余额 | Σ「待收金额」= 未结算/部分结算/挂账 台班的收入合计 | 台班记录 |
| 超期应收 | 应收中，`今天 − 日期` > 客户 `账期天数` 的部分 | 台班记录 × 客户与项目 |
| 单机日产值 | 单台设备当日收入合计 | 台班记录 × 设备台账 |

**口径声明（必须写进日报末尾）**

- 保险、年检属年度支出，不计入当日直接成本（避免单日毛利被一次性拉穿）。若要看含折旧/保险的全成本，另建月报口径。
- 「部分结算」在应收里按**未收全额**计，属保守口径；要精确到分，请在台班记录加「已收金额」字段并把「待收金额」改为 `收入-已收`。

## 2. 七个统计维度

日报默认输出前六个维度，第七个成本维度只在当日有支出时出现。

### A. 设备类型 × 吨位档
回答「今天公司靠什么车赚钱」。按 `设备类型` 分组，组内再按 `吨位档` 拆：台班数、收入、占收入比、出勤台数。
吊机与平板车要分开看——两者的台班价差 5~10 倍，混在一起会掩盖结构问题。

### B. 单台设备
- **Top 5 产值设备**：回答「谁在扛单」。
- **零出勤设备清单**：当日无台班的在册设备，标注状态（在租/待租/维修）。待租满 3 天即为闲置预警。

### C. 客户 / 项目
- Top 5 客户产值 + 回款 + 应收余额。
- 环比新增欠款：今日应收余额 − 昨日应收余额。
- 客户集中度：第一大客户收入占比（>50% 提示客户过度集中）。

### D. 业务员
按 `业务员` 分组：台班数、收入、占收入比、名次。业务员为空时归入「未指定」，**单独列出并提示补录**——这是最常见的脏数据。

### E. 项目工地
按 `项目工地` 文本分组产值，用于判断哪个工地在集中用车、哪个已收尾。

### F. 结算状态
未结算 / 部分结算 / 挂账 各自金额与占比，直接反映现金流健康度。

### G. 归属方式（自有 vs 外协）
自有设备的收入与毛利尽量高；外协设备收入大但毛利薄。外协收入占比 >40% 要提示「自有机队吃不饱」。

## 3. 预警规则

日报末尾固定输出预警清单，按红/黄两级。**没有命中就写「今日无预警」**，不要编。

| 级别 | 规则 | 判定 |
|---|---|---|
| 🔴 红 | 超期应收 | 应收记录 `今天−日期` > 客户账期天数，且金额 ≥ 5000 |
| 🔴 红 | 证照到期 | 保险/年检到期日 ≤ 今天 + 15 天（含已过期） |
| 🔴 红 | 单机毛利率为负 | 当日该设备收入 < 直接成本 |
| 🟡 黄 | 闲置 | 状态=待租 且连续 ≥3 天零台班 |
| 🟡 黄 | 未结算积压 | 未结算台班中 `今天−日期` > 30 天的条数 |
| 🟡 黄 | 业务员缺失 | 当日台班记录中 `业务员` 为空的条数 |
| 🟡 黄 | 客户集中 | 单一客户当日收入占比 >50% |
| 🟡 黄 | 外协依赖 | 外协设备收入占比 >40% |
| 🟡 黄 | 出勤率低 | 出勤率 <60%（在册 ≥5 台时） |

## 4. 环比与趋势

- **日环比**：今日 vs 昨日。
- **周同比**：今日 vs 上周同一天（`今天−7`）。机械租赁有明显周内节律，周一开工少、周三周四最忙，只比昨天会误判。
- 收入、台班数、回款三项都要给环比；变化超过 ±30% 时在结论句里点名原因（如「雨天停工」「新增包月项目」），原因只能来自备注/作业内容，不能臆测。

## 5. 数据缺失的处理

- 某张表当日无记录 → 该指标写 `0`，并在「数据完整性」里注明「回款/成本未录入」。
- 设备未上台账的台班（关联设备为空）→ 计入总收入，但归入「未关联设备」维度并提示补录，**不要悄悄丢掉**。
- 宁可写「未录入」，也不要估一个数。老板拿假数字做调度决策的代价远大于一句「没录」。
